# Opencigan 개발 로드맵

현재 운영 대상은 Raspberry Pi와 내부망 검수 환경이다. 공개 API와 원본 데이터 재제공은 이용 조건 확인과 별도 공개 승인 후에만 활성화한다. 학교 시간표 조회는 로그인 없이 제공하며, 웹과 API는 같은 데이터 처리 계층을 사용한다.

## P0 — 핵심 기능과 API

- 오늘·우리 반·학년 전체·교사별 시간표, 관측된 시간표 변경 전후 및 이력 조회.
- 기존 `/api/v1` 호환성을 유지하는 REST 계약, OpenAPI 3.1, API 문서와 Playground, CORS·요청 제한·오류 표준화.
- 학교·주차별 캐시 및 동시 요청 병합과 원본 갱신·수집 시각 및 캐시 상태 표시.
- 현재 프로세스 내 30분 캐시와 single-flight, 원본 갱신 시각과 수집 시각 표시는 기존에 구현됨. 프로세스 간 공유는 제공하지 않는다.
- 변경 이력은 최초 수집 이후 관측분만 30일 보존한다. 실제 학교 데이터의 저장은 이용 조건 확인 전 기본적으로 비활성화한다.

## P1 — 사용자 편의

- PNG·PDF 내보내기, 학교·학년·반 공유 링크, PWA 설치와 오프라인 조회.
- 주간 급식표, 과목 색상과 별칭, 복수 즐겨찾기, 시간표 검색.
- 수동 새로고침과 갱신 표시, 모바일 일간·주간 전환, 키보드·스크린리더·고대비 접근성.

## P2 — 외부 개발자 연동

- 교사·학급 필터 및 이력 API, iCalendar 구독, 임베드 위젯과 빌더.
- TypeScript·Python 클라이언트와 예제, AI Agent Skill과 llms.txt.
- API 버전·하위 호환성 정책, 이용량·응답 시간·오류율 모니터링.

## P3 — 알림 및 자동화

- 변경 Webhook 등록·삭제·관리, HMAC 서명·재시도·중복 방지.
- Web Push, Discord, Telegram, 학급별 구독과 변경 수업 선택 알림.
- 알림 빈도·방해 금지 시간, RSS/Atom 피드.

## P4 — 장기 확장

- 변경 통계, 과목별 시수, 교사 일정·충돌, 학교별 갱신 주기 분석.
- 급식 검색·알레르기 필터, 개인 일정·시험 오버레이, 모바일 홈 위젯.
- QR 공유, 서비스 상태 페이지, API 사용 대시보드, 다국어 UI.

## 구현 원칙

기존 기능과 API 호환성을 지키고 원본 요청을 최소화한다. 개인정보와 민감한 학교 정보를 불필요하게 저장하지 않는다. 읽기 API와 인증이 필요한 기능을 구분한다. 공개 전 데이터 재제공 조건을 확인하고, 인프라 이전은 기능 개발과 별도로 다룬다. 공개 터널은 사용자의 별도 승인 전 열지 않는다.
