## P0 — 핵심 시간표와 API 기반

**현재 코드에 구현됨**

- [x] 오늘/우리 반 주간/학년 비교/교사 검색 시간표 UI
- [x] 시간표 원본의 변경 표시(`isChanged`), 원본 갱신·수집 시각
- [x] 프로세스별 30분 캐시와 동일 키 single-flight, 이전 값 유지·실패 후 backoff
- [x] 프런트엔드 주간 메모리 캐시 (최대 4개 학교·주, 30분 유효, 만료·수동 새로고침 시 재검증)
- [x] Python `/api/v1` 읽기 API, JSON 오류 코드, OpenAPI 3.1, 내부망 API Playground
- [x] 프로세스별 IP당 60회/60초 요청 제한과 Origin 기반 CORS
- [x] 관측 스냅샷 비교·이력 조회 API 및 프런트엔드 UI (SQLite 저장은 기본 꺼짐)

**공개 전 필요**

- [ ] 프록시/Tunnel 경유 시 실제 클라이언트별 호출 제한 검증
- [ ] 전체 시간표/급식 및 모바일 실기기 회귀 검증
- [ ] 변경 이력 저장의 실서비스 사용 정책 및 스키마 정합성 검증
- [ ] 공개 API 운영 정책·원본 데이터 재제공 조건 확인
- [ ] 학교·학년·반을 상단 선택기·빠른 선택·즐겨찾기·공유 링크로 바꿔도 시간표, PNG, 캘린더 구독의 대상 학급이 일치하도록 개선 (학교/즐겨찾기 전환 시 실제 데이터 기반 학급 보정 및 회귀 테스트 완료, 공유 링크·구독 경로 통합 검증 잔여)
- [x] 한 날짜·교시에 복수 수업 레코드가 있을 때 일반 주간 시간표와 학년 비교에서 수업이 누락되지 않도록 표시 개선 (복수 레코드·변동 배지 회귀 테스트)
- [ ] 모바일 고정 하단 메뉴가 마지막 수업·검색 결과·입력창을 가리지 않도록 키보드·화면 회전·안전 영역 레이아웃 개선

## P1 — 사용자 편의

- [x] 오늘·우리 반 주간·교사 시간표 PNG 내보내기 (브라우저 캔버스 2배 해상도, 표시 테마 반영)
- [ ] 시간표 PDF 내보내기
- [ ] PWA 설치와 오프라인 시간표 조회
- [x] 주간 급식표 (조회한 7일 응답 재사용, 주간 이동)
- [x] 급식 하루/주간 기본 보기, 조식·중식·석식 선택, 알레르기 번호 표시 설정 (브라우저 저장, 경고 유지)
- [x] 과목별 색상/별칭 (학교별 브라우저 개인화, 기본 무채색, 교사 표시명/숨김 포함)
- [x] 애니메이션 설정 ON/OFF (브라우저에 저장, 시스템 '움직임 줄이기' 우선, 등장·버튼·새로고침 효과 제어; 현재 교시 강조 효과는 별도 후속)
- [x] 수업 데이터 기준 학급·교사명 수 및 원본 갱신 시각 표시 (선택 주 기준이며 전체 학교 규모·실제 교원 수와 다를 수 있음을 안내)
- [x] 오늘 보기의 현재·다음·남은·변동 수업 요약 및 교시 진행 상태 표시 (학교별 실제 시작·종료 시각 입력 시에만 현재/다음 판별, 브라우저 저장·입력 검증)
- [x] 복수 즐겨찾기 학교·학급 (브라우저에 최대 10개 저장, 동일 학교 전환 시 재요청 없음)
- [x] 학교·학년·반 공유 링크 (학교 정보는 URL fragment에 저장)
- [x] 선택한 학급의 주간 수업 검색 (과목·교사·요일 조합)
- [ ] 모바일 일간·주간 전환 및 접근성 보완 (학년·반 빠른 선택, 표시 설정의 시간표 하단 이동, 학년 비교 카드 레이아웃 및 터치 크기 조정 완료, 실기기 검증 잔여)
- [x] 학교나 주차를 바꾼 뒤에 이전 교사 검색어가 남지 않도록 초기화
- [ ] PNG 저장에서 긴 과목명·복수 학급·빈 교시·파일명 표시를 다듬고 모바일 다운로드 사용성 개선
- [ ] 즐겨찾기가 많아져도 화면이 길어지지 않도록 학급 전환 목록 접기·간편 선택 기능 추가
- [ ] 시간표·급식의 데이터 없음, 로딩, 갱신 실패, 이전 캐시 표시 상태를 더 쉽게 구분

현재 이미 있는 기능: 모바일 기본 '오늘' 보기, 급식 날짜 선택, 현재 주/다음 주의 수동 시간표 새로고침, 급식 새로고침, 마지막 갱신 표시, 학급 저장, 다크 모드.

- [ ] 신규 API 필터·캘린더 구독을 Playground에서 바로 시험하고 OpenAPI 명세와 실제 응답 일치 여부 자동 검사

추가 구현: 선택적으로 활성화하는 90일 가명 이용 통계, API 요청량·오류율·평균 처리 시간과 토큰 인증 관리자 화면(`/analytics.html`). 수집 거부·비동기 큐·누락 수를 지원합니다. [집계 기준](analytics.md)을 참고하세요. 공개 상태 페이지와 전체 모니터링 정책은 후속 작업입니다.

현재 이미 있는 기능: 기본 REST 계약, OpenAPI 3.1, 상대 경로 Playground, 관측 이력 API. **인터넷 공개 상태와는 별개**.

## 원칙

1. **학생용 MVP 품질을 우선**하고, 공개 API/이력 저장/알림 기능은 허용 범위·운영 안전성 검증 뒤 확장한다.
2. 기존 API 응답 계약을 유지하고 원본 서버 요청을 최소화한다.
3. 공개 API와 웹 UI는 가능하면 같은 정규화·캐시 계층을 쓴다.
4. 실제 데이터 재제공 허가·보안·변경 이력 저장과 운영 인프라 확대를 서로 독립적으로 판단한다.
5. API 문서와 구현이 충돌할 때는 테스트·실제 코드를 확인하고 문서 또는 코드를 함께 수정한다.
