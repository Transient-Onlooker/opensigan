# Opencigan 추가 기능 및 UX 개선 계획

기준일: 2026-11-14. 사용자 요청과 기존 [개발 로드맵](roadmap.md), [확인된 문제](known-issues.md)를 함께 관리합니다. 아래 체크박스는 실제 구현·검증 후에만 완료로 표시합니다.

## 진행 원칙

- 기존 API 호환성과 monochrome UI, Pretendard, Opencigan 이름을 유지합니다.
- 사용자가 바로 체감하는 오류와 모바일 사용성을 먼저 고칩니다. UI, 데이터, 배포를 작은 단위로 구현·테스트·푸시합니다.
- 사용자별 설정·알레르기 정보는 브라우저에만 저장하며 API에 보내지 않습니다. 민감한 건강 정보의 외부 전송을 피합니다.
- 시간표 수업 시각·변경 전 정보는 근거가 없으면 생성하지 않습니다. 실제 수업 시작·종료 시각은 학교별 설정 또는 확인 가능한 출처를 사용합니다.
- iCalendar 등 공개 링크는 가능한 한 \`opencigan.mcv.kr\`를 사용하되 실제 외부 접근 가능 여부를 검증하고, 기존 Tailscale 구성을 임의로 변경하지 않습니다.
- 화면 테스트는 CLI 검사와 코드 기반 검증을 우선하며 Computer Use는 사용하지 않습니다.

## P0 — 먼저 고칠 사용자 경험

- [x] U01. 공유 링크 및 캘린더 구독 링크를 다시 눌러 닫을 수 있게 하고 복사 성공·실패 상태를 알립니다.
- [ ] U02. 캘린더 구독 URL은 공개 도메인 우선. 공개 서버의 실제 \`.ics\` 경로가 작동하는 경우에만 전환합니다.
- [x] U03. 시간표 탭을 **오늘 / 이번 주 / n학년 / 교사**로 정리합니다.
- [x] U04. 새로고침 아이콘·회전 동작·성공/실패 표시를 넣고 왼쪽에 마지막 수집 시각을 배치합니다. 원본 갱신 시각은 시간표 오른쪽 아래에 작게 표시합니다.
- [x] U05. 주간 범위는 \`11.9 ~ 11.13\`처럼 표시하고 불필요한 요일 설명을 뺍니다.
- [x] U06. 급식 연결 학교명·주소 안내, 학교 저장 안내, 반복 알레르기 설명을 제거합니다. 급식 연결 실패 시 필요한 선택·재시도는 유지합니다.
- [x] U07. 교사 이름을 직접 입력하거나 목록에서 고를 수 있도록 하고, 교사별 주간 시간표를 월~금 × 교시 격자로 제공합니다. 동명이인 정보 한계도 표시합니다.
- [x] U08. 우리 반 수업 검색은 '이번 주' 보기 안에서만 노출하고, 교사 검색은 '교사' 보기 안에서 별도로 제공합니다. 검색 결과가 없을 때 안내를 표시합니다.
- [ ] U09. 모바일에서 시간표 진입 전 불필요한 요소를 줄이고 가로 스크롤과 큰 여백을 개선합니다. 접근성, 터치 영역, 상태 표시를 검증합니다. (코드에서 배치·폭 개선, 모바일 실기기 검증 대기)
- [x] U10. 전환·로딩·버튼 애니메이션을 절제하여 다듬고 움직임 줄이기 설정을 따릅니다. (시스템 설정과 사용자 OFF 설정 적용, 실기기 검증 잔여)
- [ ] U11. 오늘 현재·다음 수업 표시(학교별 교시 시각이 있는 경우만); 시각이 없으면 교시를 추측하지 않습니다.
- [x] U12. 이용 통계 관련 긴 본문·토글 UI를 메인 화면에서 빼고, 수집 범위·비활성화 방법 등 적절한 고지는 운영/개인정보 문서에서 제공합니다. DNT/GPC 보호는 유지합니다.

## P0 — 핵심 기능

- [x] F01. **알레르기 맞춤 경고**: NEIS 1~19번 항목 복수 선택, 브라우저 저장, 일간·주간 메뉴의 해당 줄에 붉은색과 경고 아이콘·번호·이름 표시. \`1\`과 \`11\`은 번호로 정확히 매칭. 원본 번호를 유지하고 미표기가 안전을 보증하지 않음을 안내.
- [x] F02. **시간표 PNG 이미지 저장**: 오늘·주간 반·교사 가능한 보기 지원, 고해상도 캔버스, 긴 텍스트 줄바꿈, 현재 테마, 학교/학년/반/날짜 포함. (실제 iOS/Android 저장 동작은 별도 검증)
- [x] F03. **전용 Favicon**: 식별 가능한 SVG와 ICO/PNG 폴백, 북마크·탭 통일.
- [x] F04. **iOS/iPadOS 홈 화면 아이콘**: 180×180 apple-touch-icon, 앱 이름, 아이콘 여백/배경, standalone 메타데이터 및 manifest. (실기기 검증은 후속)
- [x] F05. **교사별 주간 격자**: 월~금·교시·학급·과목, 동일 시간 복수 반 처리, 동명이인 한계 안내.
- [ ] F06. **모바일 시간표 압축**: 첫 화면까지 스크롤 감소, 학년·반 바로 변경, 가로 폭 최적화, 대/소 화면별 보기.

## P1 — 개인화와 표현

- [x] F07. 과목별 자동/수동 색상, 초기화, 무채색 기본 모드. (학교별 브라우저 저장; 기본은 무채색)
- [x] F08. 과목 별칭(예: 수학Ⅱ → 수2)과 원본 데이터 분리. (화면 및 PNG 표시값 적용)
- [x] F09. 교사 표시명 및 전체 접두·접미 문구 설정, 원본 이름 보존. (화면 및 PNG 표시값 적용)
- [x] F10. 교사 이름 표시/숨김. (수업 보기와 PNG에 적용)
- [ ] F11. 날짜·변경 표시·변동 배지·테두리·장소·같은 교시 복수 수업·밀도 옵션. 원본 장소 정보 부재 시 표기하지 않음.
- [ ] F12. 근거가 존재하는 변경 전·후 과목/교사 비교.
- [ ] F13. 현재 수업 강조, 끝난 수업 흐리기/숨기기, 다른 요일 흐리기, 현재/다음 교시 표시.
- [ ] F14. 학교별 실제 수업 시간표 입력/검증, 쉬는 시간·점심시간 고려.
- [ ] F15. 애니메이션 설정 ON/OFF, 등장·전환·강조 효과, prefers-reduced-motion 준수. (2026-11-14: 로컬 저장 ON/OFF와 등장·버튼·새로고침 효과 제어 완료, 현재 수업 강조 효과는 F13 구현 후 연계)
- [x] F16. 라이트/다크/시스템 테마와 PNG 반영. (시스템 설정 변경 자동 반영, CLI 회귀 검증)
- [x] F17. 실제 존재하는 학년·반 목록으로 빠르게 전환. (주간 원본 데이터가 있을 때 해당 범위로 제한; 원본 데이터 부재 시 학교급 기본 학년 표시, 모바일 실기기 검증 대기)
- [ ] F18. 데이터 기준 학급·교사 규모, 원본 갱신 시각, 부분 데이터 주의.
- [ ] F19. 오늘 현재/다음/남은/변동 수업 요약, 없는 날 안내.
- [ ] F20. 급식 기본 보기·식사 시간대·알레르기 번호 가시성 설정, 간결한 빈 상태.

## 검증 및 진행 기록

- 사용자 피드백에 따라 한 번에 모두 변경하지 않고, 문서 반영 → 작은 기능 묶음 구현 → 프런트/백엔드 테스트·보안 검토 → GitHub 푸시 순으로 진행합니다.
- 구현 후 [기존 문제 40개](known-issues.md) 및 [개발 로드맵 P0–P4](roadmap.md)의 중복·연관 항목도 함께 검토합니다.
- 실제 브라우저 모바일 검증, RPi 배포, 공개 구독 주소의 외부 접근 검증 등 수행하지 않은 항목은 완료로 표시하지 않습니다.
- 2026-11-14: 과목·교사 개인화와 같은 날짜·교시 복수 수업 표시를 구현하고 회귀 테스트를 추가했습니다. 화면 로직은 CLI 검사로 검증하며 실제 모바일 브라우저 테스트는 남아 있습니다.
- 2026-11-14: 학교·학년·반 변경과 즐겨찾기 전환 시 실제 데이터 기준 학급 보정, 시스템 테마 자동 추종 및 PNG 적용을 추가했습니다. 새 기능 배치 전 GitHub 로드맵을 다시 확인하고, 변경된 항목을 우선순위에 반영합니다.
