# 이용 통계

서버 환경에 `OPENCIGAN_ANALYTICS_DB`(SQLite 경로), 32자 이상의 무작위 `OPENCIGAN_ANALYTICS_SECRET`, 별도의 무작위 `OPENCIGAN_ANALYTICS_ADMIN_TOKEN`을 설정하면 활성화됩니다. DB와 키는 저장소 밖에 보관합니다. 미설정 상태에서도 시간표와 급식은 정상 동작합니다.

`GET /api/v1/admin/analytics?days=30`에 `Authorization: Bearer <관리자 토큰>`을 보내 조회합니다. 기간은 1~90일이며 인증 정보와 응답은 캐시하지 않습니다. 토큰은 프런트엔드 빌드 변수에 넣지 마세요.

`/analytics.html`에서 관리자 토큰을 입력하면 방문·세션·페이지 조회·API 오류율·평균 처리 시간과 일별·경로별 표를 볼 수 있습니다. API 주소는 메인 화면과 동일한 `VITE_API_BASE_URL`을 사용합니다. 토큰은 브라우저 저장소에 남기지 않으며, 잠금 버튼은 입력값·표를 지우고 진행 중인 조회를 취소합니다. 공개 화면의 방문자는 인증 없이 통계를 볼 수 없습니다.

- 방문자는 임의의 ID를 저장한 브라우저의 수입니다. 실제 사람 수가 아니며 기기 변경, 저장소 삭제, 수집 거부에 따라 달라집니다. 봇을 완전히 제외하는 지표도 아닙니다.
- 세션은 탭의 sessionStorage에 저장된 ID를 기준으로 집계합니다.
- 페이지 조회는 시간표·급식 화면 진입을 집계합니다. 브라우저의 추적 거부(DNT/GPC)와 화면 하단 수집 끄기를 따릅니다.
- 원시 방문 ID와 세션 ID는 HMAC으로 변환하며 IP, User-Agent, 학교·학급, 쿼리 문자열을 분석 DB에 저장하지 않습니다. 일반 서버 접근 로그의 보존 정책과는 별개입니다.
- 한국 시간 기준 최근 90일을 보존하고 다음 쓰기나 조회 때 만료 행을 정리합니다. 기간 방문자는 일별 방문자의 합이 아닌 중복 제거한 브라우저 수입니다.
- API 요청량은 알려진 데이터 경로의 GET/HEAD를 집계합니다. 상태 확인, OPTIONS, 분석 요청 자체는 제외합니다. 오류는 HTTP 400 이상, 평균 시간은 데이터 처리 시간입니다. 네트워크·브라우저 표시 시간은 포함하지 않습니다.
- API 통계는 최대 1,024건의 큐에 비동기로 기록합니다. 디스크 장애·큐 포화 시 시간표 응답을 기다리게 하지 않고 이벤트를 버립니다. `droppedApiEvents`는 해당 프로세스 시작 이후 누락 수이며 재시작 시 초기화됩니다. 프로세스 강제 종료 시 아직 큐에 남은 이벤트도 유실될 수 있습니다. 실시간 청구·감사 용도로 사용하지 마세요.
- SQLite WAL을 사용하고 잠금 대기는 최대 50ms입니다. 페이지 수집이나 통계 조회가 실패하면 해당 분석 API만 503으로 응답합니다.

분석 DB는 서비스 프로세스별로 따로 설정하면 조회도 분리됩니다. 여러 프로세스가 같은 DB와 같은 HMAC 키를 사용하면 저장된 수치는 합쳐지지만 큐·누락 수는 프로세스별입니다.
