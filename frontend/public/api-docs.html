Opensigan API

HTTP API reference and same-origin request playground. All sample values are synthetic. Requests use relative /api/v1/… paths.

Live requests are disabled on github.io. Use the API through a configured deployment or local server.

History is scoped by required school and week (Monday). Each change has shape {observedAt,grade,class,date,period,type,before,after}; before and after are each a {subject,teacher} object or null. Only the timetable endpoint includes cacheStatus.

Endpoints

GET /api/v1/status

Process liveness; upstream providers are not checked.

Response will appear here.

GET /api/v1/schools?q=…

Search Comcigan schools. Required query q, 1–50 characters.

Response will appear here.

GET /api/v1/neis/schools?q=…

Search NEIS schools. Requires a server-side NEIS API key.

Response will appear here.

GET /api/v1/timetable?school=…&week=…

Week is Monday of this or next week in Asia/Seoul. Response fields: schoolId, weekStart, records, sourceUpdatedAt, fetchedAt, stale, cacheStatus.

Response will appear here.

GET /api/v1/meals?school=…&from=…&to=…

NEIS school ID example B10:1234567. Inclusive date range: at most seven days.

Response will appear here.

GET /api/v1/timetable/history?school=…&week=…&cursor=…

List observed changes for the required school and Monday week. Pass nextCursor back as optional cursor. First observation establishes a baseline; history is retained for 30 days.

Response will appear here.

Responses and errors

Errors are JSON objects containing error and code.

  • 400 invalid_request: invalid or missing query values.
  • 404 not_found: unknown route.
  • 405 method_not_allowed: unsupported method.
  • 429 rate_limited: Python HTTP server client limit; observe Retry-After. Status is exempt. Worker origin refresh spacing is separate and is not a caller rate limit.
  • 503 upstream_unavailable: provider, credentials, or cache unavailable.
  • 503 history_disabled: history database is not configured.
