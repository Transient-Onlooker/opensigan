# 오픈시간표 프런트엔드

Node.js에서 `npm install` 후 `npm run dev`로 실행합니다. 개발 서버의 `/api` 요청은 `http://127.0.0.1:8000`으로 전달됩니다. 화면은 `/opensigan/` 경로에서 열립니다.

`npm run check`로 Svelte/TypeScript를 검사하고 `npm run build`로 `dist/` 정적 파일을 생성합니다. GitHub Pages 기본 경로는 `/opensigan/`입니다. 배포 빌드 시 `VITE_API_BASE_URL`에 API 서버 출처를 지정하세요. 설정하지 않으면 동일 출처 API를 사용하며, `github.io`에서는 설정 누락을 화면에 알립니다. 별도 출처의 API 서버는 브라우저 CORS를 허용해야 합니다.

학교는 한 번만 검색합니다. 학교명과 지역 교육청이 정확히 일치하는 NEIS 학교가 하나이면 급식을 자동으로 연결합니다. 같은 지역의 동명이교가 여러 곳이면 학교 주소를 확인하는 후보 선택만 표시하며 검색어를 다시 입력하지 않습니다. 기존에 저장한 급식 연결도 같은 학교인지 확인한 뒤 재사용합니다.

캘린더 메뉴에서 주간 시간표와 하루 급식을 전환합니다. 급식은 오늘을 기본으로 조식·중식·석식을 각각 표시하며 날짜 선택기와 전후 날짜 이동을 지원합니다. 같은 주의 급식은 한 번 받아 날짜를 넘길 때 재사용합니다. 화면이 다시 활성화되면 30분 갱신 주기를 확인하고, 실패 시에는 같은 학교·기간의 이전 결과를 유지합니다.

다운로드 폴더의 `catigan_ui_kit_20261113.zip`에 포함된 디자인 가이드와 예시 HTML에서 학교 정보 중심 배치, 화면별 메뉴, 모바일 하단 탐색을 참고했습니다. 구현은 기존 Svelte를 유지하며 색상·모서리·테두리는 `monochrome-ui` 기준으로 적용합니다. 키트의 가상 데이터, 스킨, 캐릭터와 고정된 현재 수업 정보는 사용하지 않습니다.
